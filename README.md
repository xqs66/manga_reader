# Manga Reader

基于 Flutter 的漫画阅读器，支持本地阅读和局域网跨设备访问。

## 功能

### 阅读

- 条漫、单页、双页多种阅读模式
- 音量键 / 键盘方向键 / 鼠标滚轮翻页
- 沉浸模式全屏阅读
- 实时调节对比度、饱和度
- 跨设备阅读同一局域网下其他设备的漫画

### 书架

- 列表 / 网格双视图
- 搜索、排序（标题 / 阅读时间 / 页数 / 随机）
- 分组管理（新增 / 重命名 / 删除 / 展开）
- 多选模式批量移动、删除

### 局域网访问

- **服务端**：将当前设备变为漫画服务器，同 WiFi 下其他设备可浏览和阅读
- **客户端**：自动扫描或手动输入 IP 连接远端服务器，连接后可浏览和阅读服务端的漫画

### 编辑

- 合并漫画为合集（文件夹或 ZIP）
- 文件夹漫画原地归档为 ZIP/CBZ

### 其他

- 浅色 / 深色 / 跟随系统主题
- 支持文件夹、ZIP/CBZ、EPUB 格式

## 运行

```bash
flutter pub get
dart run build_runner build
flutter run
```

## 打包

```bash
# 按平台批量打包，Android 分 ABI 输出到 build_output/
./build.sh
```

## 项目结构

```
lib/
├── core/           # 工具、异常处理、仓储接口
├── models/         # 数据模型
├── service/        # 服务层（日志、存储、局域网等）
├── settings/       # 设置持久化
├── database/       # 数据库（Drift）
├── routes/         # 路由
├── config/         # UI 配置
└── ui/
    ├── layout/     # 通用布局组件
    ├── pages/      # 页面（按功能分目录）
    └── widgets/    # 通用 widget
```
