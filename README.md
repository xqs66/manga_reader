# manga_reader

基于 Flutter 的本地漫画阅读器，支持文件夹、ZIP/CBZ、EPUB 格式。

## 阅读

- **阅读模式**：支持条漫、单页、双页等多种阅读模式
- **音量键翻页**：支持使用音量键前后翻页
- **键盘/鼠标**：方向键翻页、鼠标滚轮翻页，适合桌面使用
- **沉浸模式**：隐藏状态栏和导航栏，全屏阅读
- **对比度/饱和度**：阅读时实时调节画面效果

## 书架

- **列表/网格布局**：两种视图随意切换
- **搜索**：可在书架中按标题搜索漫画
- **分组管理**：按分组整理漫画，支持新增、重命名、删除分组
- **排序**：按标题、阅读时间、页数或随机排序
- **多选模式**：批量选择漫画进行移动、删除操作
- **阅读**：可打开最近阅读漫画或随机打开一本漫画

## 编辑

- **合并漫画**：将多部漫画合并为一本合集，支持输出为文件夹或 ZIP
- **归档漫画**：将文件夹漫画原地转换为 ZIP/CBZ，节省存储空间

## 更多

- **扫描路径**：支持自定义本地漫画扫描路径
- **主题**：支持浅色/深色主题

## 运行

```bash
flutter pub get
dart run build_runner build
flutter run
```
